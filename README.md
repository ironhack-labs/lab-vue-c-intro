# Hello Vue Landing Page

Hello Vue is a simple, responsive landing page built as part of Ironhack’s Vue fundamentals lab. The goal of this project is to practice the Vue 3 + Vite workflow while translating a given Figma layout into a clean, structured interface. The result is a pixel-faithful home screen that scales smoothly from mobile to desktop and mirrors the visual hierarchy of the original design.

This project focuses on core front-end skills such as Vue single-file components, template structure, styling, asset management, and responsive layout techniques. It is intentionally small and direct so the emphasis stays on understanding the framework setup and the development flow.

Tech stack: Vue 3, Vite, HTML5, CSS3, and modern JavaScript.

To run the project locally, install dependencies and start the dev server:

```bash
npm install
npm run dev
```
